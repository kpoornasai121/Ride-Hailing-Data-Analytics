# Ride-Hailing Data Analytics with SQL & Power BI

## Overview

"Ride-Hailing Data Analytics with SQL & Power BI" is an end-to-end analytics project focused on extracting business insights from a ride-hailing application’s data. The workflow involves data extraction from Excel, data preparation and transformation using SQL, and the creation of an interactive, executive-friendly dashboard in Power BI. This project demonstrates data-driven decision making for urban mobility platforms.

## Features

- Multi-sheet data ingestion and integration from Excel sources.
- Data cleaning, aggregation, and metric calculation using SQL scripts.
- Interactive Power BI dashboard visualizing:
  - Completed trips, searches, estimates, and quotes
  - Total driver earnings and conversion rates
  - Trends for trip counts, fare amounts, and distances by trip durations
  - Location-wise breakdowns and mapping
- Dynamic filtering by assembly/location for targeted analysis.
- Business-ready dashboard visuals for actionable insights.

## Technologies Used

- **SQL (MySQL Wrokbench):** Data transformation, aggregation, and metric calculation
- **Power BI:** Dashboard creation and interactive data visualization
- **Microsoft Excel:** Source of raw ride-hailing data

## How to Run

1. **Import Data**
   - Convert each relevant Excel sheet to CSV if needed.
   - Use `script.sql` to create and populate your SQL tables.

2. **Data Processing**
   - Run SQL queries to clean and structure data for reporting.

3. **Dashboard Development**
   - Import processed tables into Power BI.
   - Replicate or adapt the dashboard layout from `Image.jpg`.

4. **Interact and Analyze**
   - Use dashboard filters and visuals to explore KPIs, geographic trends, and operational efficiency.
